A tracked-cost limit, not a guaranteed cap: it counts the cost the provider reports, so calls with no reported cost aren't counted and spend can go past it, since the call that crosses it and the closing summary still run. At the limit the agent stops using tools and writes a summary of what's done and what's left. Empty means no limit; sessions can override it from the composer or /budget.
